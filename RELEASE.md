# Ozzz REI World Guide 1.2.1 — Minecraft 1.20.4 / Fabric

Небольшой справочник прямо в REI. Откройте способы получения предмета — и посмотрите, можно ли купить его у жителя, найти в сундуке или получить с моба. Для руд есть отдельная вкладка с высотами генерации.

В этой версии доступны четыре категории:

- **Обмены с жителями:** предметы, цена, рабочий блок и уровень профессии; также сделки странствующего торговца.
- **Генерация руд:** диапазон высот, измерение, размер жилы и частота генерации по поддерживаемым данным модов.
- **Добыча в сундуках:** место, зона сундука и количество по таблице добычи. Для Minecraft, When Dungeons Arise и Ad Astra добавлены русские названия.
- **Добыча с мобов:** моб, количество, вероятность выпадения и условия в подсказке. Подхватываются и модовые таблицы.

Карточки компактные: дополнительные пояснения доступны при наведении.

**Нужно:** Minecraft 1.20.4, Fabric, Java 17+, REI 14.1.727 для Fabric, Fabric Language Kotlin 1.10.20+kotlin.1.9.24+. Используемый комплект библиотек: Fabric API 0.97.0+1.20.4, Architectury 11.1.17 и Cloth Config 13.0.121.

Аддон устанавливается только на клиент.
